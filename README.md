# ThermoCore

Raumweise Heizungssteuerung für Home Assistant – Fußbodenheizung über beliebige Schalt-Relais (z. B. Shelly), mehrere Umwälzpumpen mit Vorlauf/Nachlauf, globale Soll-/Hysteresewerte mit Überschreibung pro Raum. Heizkörper und Klimageräte folgen.

**Status:** in Entwicklung (v0.1.0). Installation über HACS als benutzerdefiniertes Repository.
